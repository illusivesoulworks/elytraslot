# Elytra Slot for Minecraft 1.21.11

Unofficial NeoForge port of Illusive Soulworks' Elytra Slot 10.0.1. Requires Java 21, NeoForge 21.11.42 or later in the 21.11 series, and Curios API 14 for Minecraft 1.21.11. Curios is a separate mod. The port handles flight and glider durability through the Minecraft flight methods.

Run `./gradlew assemble` (`gradlew.bat assemble` on Windows). The result is under `build/libs`.

The optional MinecraftCapes and WaveyCapes hooks from upstream are omitted. See COPYING, COPYING.LESSER and LICENSE for license terms.
